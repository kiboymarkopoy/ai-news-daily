## Bukan Cuma GPU, NVIDIA Kini Punya CPU Andalan Buat AI Agent: Vera 88 Core

NVIDIA selama ini identik dengan GPU, tapi mereka baru aja ngeluarin **Vera** — CPU pertama yang dirancang spesial dari bawah untuk *agentic AI workloads*. Udah produksi massal, dan yang paling mengejutkan: **1.8x lebih cepat dari CPU x86** menurut benchmark Phoronix.

Vera punya 88 core Olympus buatan sendiri, memory LPDDR5X dengan bandwidth 1.2TB/s, dan teknologi Spatial Multithreading yang bikin CPU ini bisa nge-handle ribuan concurrent agent task tanpa kedip. Cocok buat workload kayak Python runtime, code compilation, database processing — semua yang jadi tulang punggung AI agent modern.

Yang bikin artikel ini menarik: **pelanggan pertama Vera termasuk Anthropic (pembuat Claude), OpenAI, SpaceXAI, NYSE, sama ByteDance.** Iya, Anthropic sama OpenAI — dua rival terbesar di dunia AI — sama-sama pake CPU buatan NVIDIA. Ironis banget.

"AI agents bakal jadi pengguna komputasi terbesar di masa depan," kata Jensen Huang. "Vera adalah CPU pertama yang didesain buat masa depan itu — built to run agentic AI at hyperscale."

Dari sisi teknis, Vera terhubung ke sistem Vera Rubin lewat NVLink-C2C dengan bandwidth 1.8TB/s. Bisa dipake standalone sebagai server CPU murni, atau jadi bagian dari platform AI factory yang lebih gede. Produsen kayak Dell, HPE, Lenovo, Supermicro, Foxconn, sama Quanta udh siap produksi massal.

Ini tanda komitmen NVIDIA: mereka gak cuma mau jual GPU, tapi seluruh stack komputasi — dari CPU, GPU, networking, sampe software — buat ngontrol pasar AI end-to-end.
