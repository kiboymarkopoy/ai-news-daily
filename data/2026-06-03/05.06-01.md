## Microsoft Kenalkan Project Solara, Sistem Operasi Android Khusus untuk AI Agent

Microsoft memperkenalkan Project Solara di ajang Build 2026. Bukan sekadar OS biasa, Solara adalah sistem operasi berbasis Android yang dirancang khusus untuk menjalankan AI agent, bukan aplikasi tradisional.

Project Solara merupakan platform dari chip ke cloud yang memungkinkan AI agent beroperasi tanpa terikat antarmuka tunggal. Microsoft membayangkan perangkat dengan layar yang antarmukanya digenerate secara real-time oleh AI, tergantung konteks dan kebutuhan pengguna saat itu. Konsep ini menjawab masalah fragmentasi yang selama ini menghantui perangkat khusus.

Microsoft mengakui ketertinggalan mereka di era mobile apps. Solara adalah upaya untuk tidak mengulangi kesalahan yang sama di era AI. Alih-alih bersaing di ekosistem aplikasi, mereka membangun OS yang native untuk agent. Perangkat Solara tidak akan memiliki "app store" dalam pengertian tradisional.

Saat ini Solara masih terbatas pada konsep hardware dan menunggu kecerdasan model AI masa depan yang dijanjikan akan segera hadir. Meskipun masih spekulatif, langkah ini menunjukkan komitmen Microsoft untuk menjadi pemimpin di era komputasi berbasis agent.
