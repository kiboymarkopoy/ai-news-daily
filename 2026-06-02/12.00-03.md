## Strava Batasi Akses API karena Serbuan Aplikasi AI Tanpa Kode

Platform olahraga populer Strava mengambil langkah tegas dengan memperketat akses API mereka. Penyebabnya? Banjir aplikasi AI tanpa kode (zero-code AI apps) dan scraper yang membanjiri platform. Mulai sekarang, developer harus membayar langganan USD 11,99 per bulan untuk bisa membangun aplikasi menggunakan data Strava.

Langkah ini diambil setelah Strava melihat lonjakan permintaan API yang tidak wajar, sebagian besar berasal dari aplikasi buatan AI yang dibuat tanpa skill coding yang memadai. Aplikasi-aplikasi ini seringkali hanya memanfaatkan data Strava untuk pelatihan model AI tanpa memberikan nilai balik ke platform.

Kebijakan baru ini menandai tren yang makin umum di industri teknologi: perusahaan mulai membatasi akses data mereka secara ketat setelah era AI scraping yang tidak terkontrol. Strava bergabung dengan deretan platform seperti Reddit, Twitter/X, dan Stack Overflow yang telah menerapkan biaya API untuk pengguna komersial.
