## GitHub Copilot Ganti Sistem Harga, User Kaget Tagihan Bisa Ratusan Dolar Sehari

GitHub resmi memberlakukan sistem harga baru berbasis pemakaian (usage-based pricing) untuk Copilot hari ini. Hasilnya? Gempar di komunitas developer. Banyak pengguna melaporkan tagihan membengkak drastis dalam waktu singkat.

Beberapa pengguna bahkan menghabiskan jatah kredit AI bulanan mereka hanya dalam sehari. Sistem baru ini menggantikan model lama yang berbasis jumlah request, di mana satu chat dan sesi coding berjam-jam dihargai sama. Kini, setiap prompt dihitung berdasarkan jumlah token input dan output, plus model AI yang digunakan.

Misalnya, 1 juta token output dari GPT-5.4 nano hanya $1.25, tapi model frontier seperti GPT-5.5 bisa mencapai $30 untuk jumlah token yang sama. Sistem "Auto mode" yang memilih model otomatis juga bikin pengguna kelabakan karena kadang pindah ke model mahal untuk query sederhana. Beberapa pengguna menyebut kebijakan ini "terlalu mahal" dan ada yang mulai melirik kompetitor.

Test sederhana dari Ars Technica membuat game Minesweeper via Claude Haiku 4.5 menghabiskan 94 kredit. Hitung sendiri kalau Anda sering pakai Copilot untuk proyek besar. Pertanyaan besar kini: apakah developer akan tetap setia atau mulai migrasi ke alat coding AI lain yang lebih ramah kantong?
