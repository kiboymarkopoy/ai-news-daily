## Microsoft Siap Umumkan Model AI Baru di Konferensi Build

Microsoft bersiap menggelar konferensi Build di San Francisco pekan ini, dan bocoran awal menunjukkan perusahaan akan mengumumkan model AI baru serta sejumlah peningkatan besar untuk Windows. Konferensi yang biasanya digelar besar-besaran kali ini mengambil format lebih intim, menandai momen penting bagi raksasa software tersebut.

Menurut laporan The Verge, Microsoft diprediksi akan meluncurkan model reasoning baru dari divisi Microsoft AI. Selain itu, perusahaan juga dikabarkan akan memperkenalkan aplikasi Copilot "super app" yang menggabungkan berbagai layanan AI mereka dalam satu platform. Ini bisa menjadi langkah besar setelah sebelumnya Microsoft mengintegrasikan Copilot ke berbagai produk seperti Office, Windows, dan GitHub.

Peningkatan Windows juga akan menjadi sorotan utama. Microsoft dikabarkan akan menghadirkan mode developer baru dan fitur AI yang lebih mendalam di sistem operasi. Langkah ini dilakukan untuk merebut kembali kepercayaan para developer yang belakangan mulai goyah akibat kebijakan kontroversial seperti sistem pricing GitHub Copilot yang baru.
